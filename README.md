# SIPESURAT Sekolah

Prototype penomoran surat sekolah menggunakan React + TypeScript + Vite.


## Menjalankan

```bash
npm install
npm run dev
```

Build production:

```bash
npm run build
```

## Format nomor

`421/001/SD.25/KEP/IX/2026`

Nomor urut diisi otomatis oleh sistem dan tetap boleh diubah manual sebelum disimpan.
